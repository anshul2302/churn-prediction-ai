
# Churn Prediction AI

A portfolio project demonstrating a **Customer Churn Prediction** model with an interactive **Streamlit web app**.  
Users can upload customer data in CSV format and get churn probability predictions along with feature importance visualization.

---

## 📌 Project Description
Customer churn is a critical metric for businesses to monitor. This project:
- Builds a **Logistic Regression pipeline** using scikit-learn.
- Preprocesses data with one-hot encoding and scaling.
- Saves the trained model and feature names for inference.
- Provides a **Streamlit app** for easy interaction:
  - Upload CSV → Predict churn probability.
  - View top features impacting churn.

---

## 🛠 Tech Stack
- **Python 3.9+**
- **Streamlit** (UI)
- **scikit-learn** (model training)
- **pandas** (data manipulation)
- **joblib** (model persistence)
